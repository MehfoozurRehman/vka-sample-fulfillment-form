# VKA Sample Fulfillment Form

A high-performance order fulfillment intake and customer sample request form built with Next.js App Router (Turbopack), React 19, Tailwind CSS v4, and Radix UI.

## Overview

`vka-sample-fulfillment-form` provides a streamlined sample request and order intake process for VKA fulfillment operations, featuring accessible form components, real-time validation, and modern UI primitives.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Frontend Core**: React 19, TypeScript
- **UI & Components**: Radix UI Primitives, Lucide Icons
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`, `tw-animate-css`)

## Prerequisites

- Node.js (v20 or higher recommended)
- Package manager (`pnpm` recommended)

## Getting Started

1. **Install dependencies**:
   ```bash
   pnpm install
   ```

2. **Run the Development Server**:
   ```bash
   pnpm dev
   ```

3. **Access the Application**:
   Open `http://localhost:3000` in your web browser.

## Available Scripts

- `pnpm dev` - Starts the Next.js development server with Turbopack.
- `pnpm build` - Creates an optimized production build.
- `pnpm start` - Runs the production server.
- `pnpm lint` - Runs ESLint code quality checks.
